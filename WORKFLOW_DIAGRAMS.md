# مخططات تدفق العمل - Workflow Diagrams

## 📊 نظرة عامة

هذا الملف يحتوي على مخططات تدفق العمل (Workflows) لجميع العمليات الرئيسية في نظام الكاشير.

## 1. 🔄 تدفق العمل الكامل للوردية (Full Shift Workflow)

```
┌─────────────────────────────────────────────────────────────┐
│                    بدء الوردية (Start Shift)                 │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  1. Check Start Shift                                        │
│     GET /api/cashier/check-start-shift                      │
│     ✓ التحقق من إمكانية بدء الوردية                         │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  2. Start Shift                                             │
│     POST /api/cashier/start-shift                           │
│     Body: { cashier_id, start_amount, ... }                 │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
┌─────────────────────────────────────────────────────────────┐
│              عمليات الوردية (Shift Operations)               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  • إنشاء الطلبات (Create Orders)                      │  │
│  │  • تحديث حالات الطلبات (Update Status)               │  │
│  │  • إضافة مصروفات (Add Expenses)                      │  │
│  │  • تسوية دفعات التوصيل (Settle Deliveries)           │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  3. End Shift                                               │
│     POST /api/cashier/end-shift                             │
│     Body: { total_mony }                                    │
│     ✓ إنهاء الوردية وحساب العجز/الفائض                    │
└─────────────────────────────────────────────────────────────┘
```

## 7. 🔄 تدفق تحديث حالة الطلب (Order Status Update Flow)

```
                    Order Status State Machine
                    
┌──────────────────────────────────────────────────────────────┐
│                         PENDING                               │
│                       (تم إنشاء الطلب)                        │
└──────────────────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ↓                   ↓                   ↓
  ┌─────────┐         ┌─────────┐        ┌─────────┐
  │  DONE   │         │  DONE   │        │ RETURN  │
  │(Takeaway│         │(Delivery│        │ (Cancel)│
  │  /Dine) │         │)        │        │         │
  └─────────┘         └─────────┘        └─────────┘
        │                   │
        ↓                   ↓
  ┌─────────┐         ┌──────────────┐
  │ PICKUP  │         │OUT_OF_       │
  │(Customer│         │DELIVERY      │
  │  Takes) │         │⚠️ Requires   │
  └─────────┘         │delivery_id   │
                      └──────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ↓                   ↓                   ↓
  ┌──────────┐        ┌──────────┐       ┌──────────┐
  │DELIVERED │        │ RETURN   │       │FAILED_TO_│
  │(Success) │        │(Returned)│       │DELIVERED │
  └──────────┘        └──────────┘       └──────────┘
        │
        ↓
  ┌──────────────────┐
  │ SETTLE_PAYMENT   │
  │ (if unpaid COD)  │
  └──────────────────┘
```

### حالات حسب نوع الطلب:

#### Takeaway:
```
pending → done → pickup → (end)
pending → return → (end)
```

#### Dine-in:
```
pending → return → (end)
(usually paid immediately, no further status)
```

#### Delivery:
```
pending → done → out_of_delivery → delivered → settle_payment → (end)
pending → done → out_of_delivery → return → (end)
pending → done → out_of_delivery → failed_to_delivered → (end)
pending → return → (end)
```

## 9. 🎯 نقاط القرار الحرجة (Critical Decision Points)

```
                    ┌─────────────────┐
                    │ Checkout        │

                    ┌───────┴────────┐
                    │ Payment Type?  │
```
